# 优酷普通 4K 修复

1. 用同一账号、同一影片复查手选菜单和「智能」实际解码结果。根据 [诊断与适配](references/diagnose.md) 找活动客户端、活动播放器资源、手选档和自适应档，避免用菜单文字判断实际分辨率。
2. 先运行 `node scripts/youku-patch.cjs status [安装目录]`。脚本从播放页定位播放器缓存，再按画质映射、流查找和菜单结构自动匹配。参考 [补丁使用](references/patch.md) 执行应用、保护和恢复。确认用户授权后才应用对应变更，完全退出优酷再修改文件。
3. 新版结构发生变化、缓存缺失或有多个候选时，按 [诊断与适配](references/diagnose.md) 重新确定实际加载的脚本和已授权的档位。若只有智能档可用，可新增选项固定同一播放列表原本可用的普通 SDR 4K，沿用同一账号、许可校验和 DRM。出现可用的原生 4K 项时沿用原生项。先在副本验证补丁和回滚，再应用到客户端实测切档。
4. 以实际菜单、手选后解码或渲染的 4K 首帧、同一播放会话只使用一个普通 4K 档为验收。再正常启动一次。对后台更新保护，检查实际触发日志。对未触发的远程清理，应标为只做了源代码和分支测试。

分享时只打包自写脚本、适配记录和安装/还原说明。从最终 ZIP 解压并检查其中的文件后再交付。播放器原包、补丁后的厂商完整脚本、备份、账号文件、调试日志、带签名的播放地址、片单和机器路径留在本机。
